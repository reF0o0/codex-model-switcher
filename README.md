# Codex 模型切换器 1.6.0

原版本日期：2026-10-19。本次补齐仓库发布记录。

- 界面改为“切换模型 / 会话 / 备份 / 文件权限”四个顶部入口，文件访问权限不再占用主页面。
- 待处理会话默认折叠，只在会话页按需展开；支持逐条忽略和恢复全部忽略，忽略记录重启后保留。
- 历史页收拢行内操作，保留“打开”和“更多”菜单；搜索会同时匹配标题与完整会话 ID，并强制刷新结果。
- 搜索能力改为按 `models.json` 中当前模型的声明判断，不再写死 V4 Pro；`deepseek-flash` 已声明支持时可正常开启。

# Codex 模型切换器 1.5.0

原版本日期：2026-10-19。本次补齐仓库发布记录。

- 窗口直接显示最近切换的迁移、跳过和未检查数量，以及待处理会话与诊断、接续入口；历史页可筛选待处理记录。重开工具仍能查看上次结果。
- 新增单会话只读诊断，区分历史格式、额度、频率限制、网络、登录和文件权限问题；显示检查时间、证据与建议，不发送模型请求。
- 接续失败后优先恢复已有关联，不再重复创建会话和注入历史；保留创建与验证进度，运行中不重复发送，已完成的同模型验证不重复消耗额度。恢复失败时保留原关联。
- 区分未检查、本地格式检查和接续验证；切换模型后旧验证结果失效。后端错误只显示固定分类与建议，避免透出原始错误中的敏感内容。
- 修复会话接口应答前到达的完成通知被丢弃的问题。窗口点击、系统授权弹窗与布局验收按用户安排暂缓。

## 安装包与源码

这是历史安装包补档，保留原包和原签名。该版本未保存完整 Swift 界面源码；对应标签只包含版本说明、校验信息和从安装包恢复的 Python 后端，不应视为完整应用源码。

附件包含 Apple Silicon macOS 应用 ZIP 和 SHA-256 校验文件。历史版本的行为与限制以当时版本为准，日常使用建议选择最新版本。

# Codex 模型切换器 1.5.1

原版本日期：2026-10-19。本次补齐仓库发布记录。

- 配置缺失、TOML 损坏或非 UTF-8 时，仍可读取有效备份并从窗口恢复；恢复前完整校验备份，原损坏配置单独保留，不覆盖新增消息。
- 应急恢复不会写入脱敏占位密钥；可从钥匙串取回 DeepSeek 密钥，其他缺失密钥需重新填写。正常配置下继续只回退本工具管理的设置。
- 应急安全快照缺少有效配置时不作为恢复选项；清理独立保护最近三份含有效配置的恢复点，避免失败重试挤掉唯一可用备份。
- 接续等待期间的单次 45 秒静默不再提前终止整个验证；最多等待 150 秒，超时保留关联和未确认状态，并提示打开原接续检查。
- 单会话诊断不再因其他会话文件不可读而误报目标会话权限问题；未读到的其他文件会明确提示，目标本身不可读仍报告权限错误。

- 发布构建要求固定证书身份，拒绝临时签名；身份变化时停止安装，避免反复丢失 macOS 对应用身份的识别。
- 保留原授权记录设置键，启动时刷新过期但可用的目录书签；恢复或刷新失败时保留旧记录。
- 已完成本机代码签名信任设置，从旧临时签名迁移安装；窗口文件读写检查通过。内容不同的两个签名应用校验为同一固定身份。
- 修复专用钥匙串不在搜索列表时 codesign 找不到身份的问题；仅在签名期间临时加入，成功或失败后均恢复原搜索列表。

# Codex 模型切换器 1.4.1

原版本日期：2026-10-19。本次补齐仓库发布记录。

- 新增常驻的“文件访问权限”区域：启动和操作前检查配置、会话数据库、历史和备份目录，列出无法访问的具体路径；没有权限时暂停写入。
- 新增“申请目录访问”与“系统权限设置”入口，使用系统目录选择窗口申请访问；选择目录后重新实测，不把点过按钮视为已授权。
- 权限检查独立于备份初始化，首次启动失败也能看到检查结果。检查不改现有文件内容，用临时文件验证目录写入、重命名和删除。
- 后端从用户主目录启动，避免继承受保护文稿目录作为工作目录；应用附带系统隐私访问用途说明。

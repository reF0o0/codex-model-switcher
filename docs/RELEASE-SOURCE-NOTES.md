运行源码由保留的 1.7.0 修改前备份恢复，未修改的 Python 模块与当时安装包逐文件一致。没有保存的辅助文档和 Swift 检查沿用 1.6.4 基线；Python 搜索控制测试来自保留的同一功能版本。此标签是恢复后的可构建源码，不声称逐文件还原当时全部开发文件。

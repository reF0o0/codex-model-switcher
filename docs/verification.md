# 验证记录

更新日期：2026-10-19（Asia/Shanghai）。运行环境：Apple Silicon Mac，macOS 26.7.1，Python 3.13，Codex 0.162.0-alpha.17.2。

## 后端

102 项单元测试通过，使用临时 SQLite 数据库和普通文件验证实际行为：

- GPT/DeepSeek 双向切换，消息正文、文件字节长度、原会话 ID、归档状态、ChatGPT 登录保持。
- 文件头与数据库服务商同步，避免重新扫描时路由被改回。
- 恢复保留备份之后新增的消息与会话。
- 数据库拒绝写入时，配置与文件头回滚，保留恢复标记。
- 无效服务商/模型组合在更改前被阻止。
- 备份过期与数量清理、最近三份保护、共享内容去重、路径越界/符号链接隔离。
- 损坏快照校验失败时停止恢复。
- 兼容文本不含旧推理和工具输出；无关自定义服务商不被迁移。
- 更新 DeepSeek 密钥会同步有效服务商定义，不覆盖 ChatGPT 凭据。
- 带空格、换行、`Bearer ` 前缀或引号的粘贴内容会被清洗后保存，并回报清洗了什么。
- 全角连字符、弯引号、字段名和多行粘贴会被归一化并提取出密钥；太短的输入直接报告字符数。
- 密钥写入 macOS 钥匙串；配置缺失 token 时，切换会从钥匙串回填。
- 备份里的 `config.toml` 不含明文 token；恢复时使用当前配置或钥匙串中的密钥。
- 「只修复」保持服务商、模型和推理强度不变，只对齐会话文件头与数据库路由，并先创建备份。
- 空输入、超长内容、非 ASCII 密钥分别给出各自的错误原因，不再共用一个「格式无效」。
- 读取进程列表被系统拒绝时，状态查询仍可用并标记为「无法确认」，写操作明确拒绝而不是冒险覆盖配置。
- 文件与目录发布均同步落盘；恢复再次被中断时，仍保留最初的恢复点。
- 自动/手动修复 DeepSeek 推理回放项，逐字匹配已有历史展示事件；所有行长度、正文、附件引用与工具记录保留。
- 未知格式、压缩历史中的未知推理项跳过并列出原因；批量处理保留该会话的原文件和路由。
- 重复执行幂等，GPT 推理记录和 DeepSeek 目标切换不做这项转换。
- 修复期间数据库写入失败回滚，断电模拟后的恢复可重试；恢复保留追加消息，已被其他操作编辑的区段拒绝覆盖。
- 切回 DeepSeek 时按修复备份还原原始推理区段，往返后正文逐字节一致；追加消息保留。
- 修复位置被编辑过的会话在还原时跳过并报告原因；仍需要的修复备份受到自动清理保护。

## 1.3.1 回归验证

- 归档/移动后按会话 ID 定位，原路径被另一会话占用时不覆盖该文件；多个候选无法唯一确认时不写入并保护备份。
- 多批修复按区段合并，同一区段不重复还原；任何一批发生冲突时保留整个会话。共享会话 ID 的多个文件分别处理、会话数量去重。
- 切回 DeepSeek 在文件替换后、配置写入后分别模拟强制中断，恢复后 GPT 历史格式、配置和路由一致；恢复再次遇到数据库故障后可重试。

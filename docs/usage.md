# Codex 模型切换器

这是一款本机 Mac 应用，用来在 GPT 与 DeepSeek 之间切换，并让以前的本地会话保留、可查找。适配当前这台 Apple Silicon Mac、Python 3.13 与 Codex 0.162.0-alpha.17.2；不修改 ChatGPT 云端聊天。

## 第一次使用

1. 打开同目录的「Codex 模型切换器.app」。你也可以把它拖到「应用程序」文件夹。
2. 先读完当前回复，再在 ChatGPT/Codex 按 **⌘Q 完全退出**；只关窗口不算退出。
3. 回到切换器，选择 GPT、`gpt-6.1-sol` 和 High，点击「备份并切换全部会话」。工具会先备份，再迁移；首次备份可能需要一两分钟。
4. 完成后点击「打开 ChatGPT」。原会话保留原 ID、名称、项目与归档状态。已归档的会话不会被自动取消归档。

切换器检测到 ChatGPT/Codex 正在运行时，会禁用切换、备份、恢复和新建接续，避免与正在写入的聊天记录冲突。回到切换器时会自动刷新，也可以手动点「刷新」。

如果按 ⌘Q 后仍提示正在运行，请关闭仍在运行的 Codex 命令行/后台任务，或结束其他设备发起的任务后刷新。

## 旧会话无法直接回复时

实际测试确认：旧 DeepSeek 的推理记录格式可能被 GPT 拒绝。模型切换只能处理路由，不能保证所有厂商的原始推理记录互相兼容。

1. 退出 ChatGPT，回到切换器的「全部历史」。
2. 搜索旧会话，点击「兼容接续」。这会使用一次当前模型的请求额度。
3. 工具保留原会话，建立一个带「GPT接续」或「DeepSeek接续」名称的关联会话，并自动打开。
4. 后续在关联会话继续；工具中也可以选择「原会话」或「打开接续」。

接续只携带用户与助手的可见文本，排除旧厂商推理记录和工具调用数据。超长对话默认带入最近 80,000 字符；完整可见文本另外保存在本机，路径会提供给新会话。图片、附件和完整工具记录继续保留在原会话，并不自动转成文字或重新上传。不是对原对话全部内部状态的无损转换。

## 再切回 DeepSeek

退出 ChatGPT，在切换页选择 DeepSeek 与 `deepseek-flash`（或 `deepseek-v4-pro`），点击「备份并切换全部会话」。默认复用你已配置的 DeepSeek API key；ChatGPT 登录凭据不变。以后换回 GPT 也一样。

DeepSeek 使用自己的 API 余额；GPT 使用你当前 ChatGPT 登录对应的可用额度。工具不经过第三方中转。可见会话内容只有在你发起续聊/兼容接续时，才会发送给所选模型服务商。

## 备份自动清理

默认开启：保留最近 **10 份**成功备份，最长 **30 天**；始终保留最近 **3 份**，即使超过 30 天。可以在「备份与恢复」修改数量与天数，或关闭自动清理。

自动清理发生在打开切换器和成功备份后。工具关闭时不常驻、不创建系统定时任务；再次打开时会补做过期清理。「立即清理」可以手动执行。

相同文件内容去重保存；完整快照包括配置、会话文件、状态数据库、分页历史数据库，以及已有接续的关联信息与文本导出。成功备份的数量和过期时间控制快照保留；多个快照共用的内容，直到没有快照引用时才清理。

清理只处理工具专用目录中具有有效清单的自建备份，不清理会话、手动导出文件或别的备份目录。自动删除的旧备份不能从本工具恢复。异常中断且无有效清单的残留不会被贸然删除，可以在确认后人工处理。

填写的密钥会先做清洗：去掉首尾空白、内部空格与换行、不可见字符和 `Bearer ` 前缀；仍不合法时会说明原因（空输入、超长、或含有不允许的字符及编码）。保存密钥和切换一样，需要先按 ⌘Q 退出 ChatGPT，否则「保存密钥」按钮是灰的。

备份目录：`~/.codex/provider-switcher/backups`。目录权限为仅本机当前用户可访问，内容不是加密存储。备份包含历史文本与配置中的 DeepSeek 密钥，请妥善保管。

## 恢复

退出 ChatGPT，在备份页选择一份备份，点击「恢复选中备份」。恢复前会校验快照并再做一份安全备份。

恢复操作回退模型与服务商路由，保留恢复点之后的新会话、新消息。它不会用旧数据库覆盖整个历史，也不会回退 ChatGPT 账号登录或其他无关配置。完整历史快照保留用于需要人工处理的灾难恢复。

如果切换中途断电或被强行终止，工具会显示未完成操作标记；先选择备份恢复，再继续切换。

## 实现与范围

- 仅更改本机 GPT/DeepSeek 会话的服务商、模型、推理强度，以及聊天文件头中的服务商信息。同步文件头时保持原字节长度，分页偏移与消息正文不变。
- DeepSeek 使用内部服务商 ID `ds_api`。它与 `openai` 一样长，是为了保证以后切换紧凑文件头时也不挪动分页偏移；显示名称仍是 DeepSeek。原有 DeepSeek 定义保留。
- 统一历史列表包括所有服务商与已归档会话；其他服务商的会话不批量迁移。旧 `custom` 定义仅在明确指向 `api.deepseek.com` 时归入 DeepSeek。
- 不修改 ChatGPT/Codex 应用本体，不依赖后台监听，不接管或退出正在运行的任务。
- 本工具使用本地状态格式和实验性的 Codex app-server 接口。应用升级若改变格式，工具可能停止工作；遇到“不支持的数据格式”时先保留备份再更新工具。
- 开发时已在独立副本验证双向路由、扫描后仍可见、消息保留，并实测 GPT 与 DeepSeek 的兼容接续。原始会话尚未批量迁移，需要按上面的步骤退出 ChatGPT 后执行。

## 源代码

仓库提供 SwiftUI 界面、Python 后端、测试和构建脚本。无第三方 Python 依赖，需 Python 3.11 或以上。

运行测试：在仓库根目录执行 `python3 -B -m unittest discover -s tests -v`。

重新构建：在仓库根目录执行 `zsh scripts/build.sh`，应用生成在 `dist` 子目录。
